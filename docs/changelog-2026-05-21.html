⛒权限系统升级

角色由 3 级扩展为 4 级，并新增了员工级别的数据可见性控制。

角色权限范围
平台管理员 cjx 所有企业、所有权限
超级管理员 NEW 企业内最高权限：创建账号、设角色、设数据范围、改企业配置
管理员 后台访问，只能编辑普通用户的密码和显示名，不能创建账号
普通用户 仅看板访问，受数据范围限制
平滑迁移：原有的"管理员"账号已自动升级为"超级管理员"，权限完全保留，无需任何操作。

+新增「数据查看范围」

超级管理员可在「后台 → 用户管理」中为每个账号设置可查看的负责人范围：

  • 全部数据（默认）：看公司全部经营数据
  • 指定负责人：勾选具体的负责人名字，该用户只能看到这些人的数据

举例：

  • 设置 小红 的数据范围 = [小红] → 小红登录后看板上只显示她自己的经营数据
  • 设置 店长 的数据范围 = [小红, 小蓝] → 店长可以看小红 + 小蓝两人的数据
安全保障：
  • 限制在后端 SQL 层执行，浏览器无法绕过
  • 受限用户的"负责人"下拉框只显示其有权查看的名字，连其他人的存在都感知不到
  • 超级管理员和平台管理员永远看全部数据，不受此限制

⚠需要您操作的事项

仅超级管理员需要关注，普通用户和管理员可忽略。

① 检查"固定利润率"是否符合贵司实际

进入「后台 → 企业配置」，确认"固定利润率"是否为贵司实际数值。默认 13%，可在 0-99 之间任意设置。

② 为每位员工设置数据查看范围

进入「后台 → 用户管理」：

  1. 找到对应账号，点「编辑」
  2. 在「数据查看范围」处选择「指定负责人」
  3. 勾选该员工可看的负责人名字
  4. 保存

设置完成后，该员工再次登录看板就会只看到自己被授权的那部分经营数据。
